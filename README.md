# TRM Properties

## Project Overview
TRM Properties is a professional real estate platform operating in prime commercial and residential zones across Gauteng, specifically focusing on **Sandton** (Johannesburg) and **Menlyn** (Pretoria). The website provides property listings, interactive location maps, detailed enquiries, and general client communication channels.

---

## Features Implemented (Part 3)
* **Interactive Elements:**
  * Implemented an interactive **FAQ Accordion** using HTML, CSS, and JavaScript for seamless user interaction.
  * Added an image **Lightbox Gallery** for high-resolution property viewing.
  * Embedded dynamic, dual **Leaflet.js maps** pinpointing the Sandton and Menlyn office locations.
* **Dynamic Content & Search:**
  * Developed a real-time, dynamic **property search and filter bar** using JavaScript DOM manipulation to instantly sort listings without page reloads.
* **Form Functionality & AJAX:**
  * Created separate, purpose-driven forms on **`enquiry.html`** (for services, costs, and product details) and **`contact.html`** (for general messages)[span_2](start_span)[span_2](end_span).
  * Built robust **client-side JavaScript validation** and visual error handling[span_3](start_span)[span_3](end_span).
  * Integrated **AJAX form submission** (via the Fetch API) for asynchronous, smooth communication[span_4](start_span)[span_4](end_span).
* **Search Engine Optimization (SEO):**
  * Configured unique **meta tags**, descriptive title tags, and image alt attributes.
  * Added a **`robots.txt`** file to manage search engine crawlers[span_5](start_span)[span_5](end_span).
  * Generated a **`sitemap.xml`** file to outline site structure[span_6](start_span)[span_6](end_span).
